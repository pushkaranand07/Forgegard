# External audit — November 2026

Audit of commit `c78cac117` (branch `remediation`), run on 2026-11-07 on Windows 11,
Ryzen 7 4800H, 15.4 GB RAM, CPU only. Issue IDs `I1`–`I22` are referenced by
[remediation.md](remediation.md) and by commit messages (`fix(I5): …`).

**Overall: 5.2 / 10.** The serving layer is solid (hash-verified safe model loading,
request IDs, consistent errors, 77 meaningful tests). The image detector performs at
chance, the documented concurrency guarantees fail under a real threaded server, a
single upload can exceed the compose memory limit, and the weights cannot be obtained
by anyone but the author.

## What was run

- Fresh `git clone`, Python 3.13 venv, README steps exactly: pip 662 s, `npm ci` 22 s,
  `npm run build` 4 s. About 12 minutes to first run, only because local weights were copied in.
- `pytest` 77/77 (weights present), coverage 74 %, ruff (project rules) clean,
  broad ruleset 258 findings, mypy 13 errors, pip-audit 39 CVEs, npm audit 0.
- Production-like server: `DEBUG=false`, `collectstatic`, waitress with 4 threads
  (mirrors gunicorn `gthread` / `threads=4`). Black-box HTTP tests, Playwright + axe,
  Lighthouse, threaded load tests, peak RSS sampling of the server process.
- Labelled sets built for the audit:
  - **Images (80):** 20 base frames × {authentic, spliced} × {single JPEG q92,
    background previously q75 then saved q92}. Splice = a 180–320 px patch from another clip.
  - **Videos (18):** 8 real talking-head segments, 8 face-swapped versions of the same
    segments (MTCNN + `seamlessClone`), 2 no-face clips.

Not tested: Docker (not installed; everything about the image is static reading only),
GitHub Actions, CUDA, public benchmarks (CASIA, Celeb-DF), the Vercel deployment.

## What was good

- Fail-safe model loading: manifest hash check before deserialising, `weights_only=True`,
  strict keys, failures surfaced in `/api/health/`, covered by tests.
- Validation on the main API: every malformed input returned a correct 4xx JSON error
  with no paths or stack traces; static-file traversal returned 404.
- Tests assert real behaviour (RGB order, golden samples pinned to weight hashes, no leakage).
- Frontend: strict TypeScript, good loading/error/empty states, zero console errors.
- Honest documentation of scope and limitations.
