🛡️ About ForgeGuard

An AI-powered tool for detecting deepfake videos and digital image forgeries.

🎯 Project Objective

ForgeGuard is my final-year deep learning project that aims to detect AI-generated (deepfake) media and manually manipulated images. The system identifies facial swaps in videos and pixel-level tampering in photos created using techniques such as Generative Adversarial Networks (GANs), Diffusion models, or Adobe Photoshop.

The system analyses uploaded media and classifies it as either AUTHENTIC or TAMPERED, along with a confidence percentage.

🧠 Model Architecture

The detection pipeline utilizes two specialized architectures optimized for different media modalities:

  1. EfficientNet-B7 (Video Deepfake Detector) – A powerful 66-million parameter backbone pre-trained on the Noisy Student dataset. It extracts dense spatial features from facial crops to identify microscopic generative artefacts, boundary inconsistencies, and latent space errors typical of deepfake algorithms.
  2. IMDModel & ELA (Image Forgery Detector) – A dedicated pipeline for static images that combines Error Level Analysis (ELA) with a custom CNN. It detects localized differences in JPEG compression levels, exposing regions that have been spliced or digitally altered.

The system employs a Confident Aggregation Strategy for video analysis, sampling multiple frames and requiring a high-consensus threshold to ensure forensic reliability.

📥 Supported Inputs

  • Videos: mp4, avi, mkv, webm, gif, 3gp, wmv, flv — up to 100 MB
  • Photos: jpg, jpeg, png, webp — up to 20 MB

Face detection is performed automatically using the MTCNN (Multi-task Cascaded Convolutional Networks) engine before inference. The system intelligently isolates facial regions of interest to maximize detection accuracy.

⚠️ Limitations

  • The model was trained on a specific deepfake dataset and may not generalise equally well to all manipulation techniques.
  • Very low-resolution or highly compressed media may reduce detection accuracy.
  • Inference time on CPU is significantly slower than on a CUDA-capable GPU.
  • The tool is intended for educational and research purposes; results should not be treated as definitive legal evidence.
