About DeepGuard

An AI-powered tool for detecting deepfake videos and photos.

🎯 Project Objective

DeepGuard is my final-year deep learning project that aims to detect AI-generated (deepfake) media – videos or photos in which a person's face has been synthetically altered or entirely generated using techniques such as Generative Adversarial Networks (GANs) or face-swap algorithms.

The system analyses uploaded media and classifies it as either REAL or FAKE, along with a confidence percentage.

🧠 Model Architecture

The detection pipeline combines two complementary deep learning components:

  1. ResNeXt-50 (Spatial Feature Extractor) – A convolutional neural network pre-trained on ImageNet. The final classification layers are removed, and the remaining backbone extracts a rich spatial feature map for each video frame, capturing texture, lighting, and blending artefacts that are common in manipulated faces.
  2. LSTM (Temporal Sequence Modeller) – A Long Short-Term Memory recurrent network processes the per-frame feature vectors in order. It learns temporal inconsistencies across frames — unnatural blinking, flickering boundaries, and motion artefacts — that would be invisible when examining any single frame in isolation.

For photo inputs, a single image is replicated into a pseudo-video sequence before being passed through the same pipeline, making the model reusable for both tasks.

📥 Supported Inputs

  • Videos: mp4, avi, mkv, webm, gif, 3gp, wmv, flv — up to 100 MB
  • Photos: jpg, jpeg, png, webp — up to 20 MB

Face detection is performed automatically using the face_recognition library before inference. If no face is found, the full frame or image is used instead.

⚠️ Limitations

  • The model was trained on a specific deepfake dataset and may not generalise equally well to all manipulation techniques.
  • Very low-resolution or highly compressed media may reduce detection accuracy.
  • Inference time on CPU is significantly slower than on a CUDA-capable GPU.
  • The tool is intended for educational and research purposes; results should not be treated as definitive legal evidence.
